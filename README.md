> ### АНТИВИРУСЫ
> Антивирус может отреагировать на WinDivert.  
> Для работы zapret нужен WinDivert — инструмент перехвата и фильтрации сетевого трафика.
> Его могут применять как безопасные, так и вредоносные программы, однако сам WinDivert вирусом не является.
>
> **Фрагмент [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) из репозитория [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Некоторые антивирусы считают файлы WinDivert потенциально опасными либо относят их к хакерским инструментам. В результате файл удаляется и отправляется в карантин. Название обнаружения обязательно содержит `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`
>
> Добавьте каталог с zapret в исключения антивируса или отключите обнаружение PUA (потенциально нежелательных приложений). Например, Kaspersky предлагает параметр "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Если вы уверенно настраиваете исключения, лучше добавить исключение; при недостаточном понимании настроек рекомендуется отключить обнаружение PUA.

## ⚙️Использование

1. Сначала включите безопасный DNS (Secure DNS)
    * В Chrome включите "Использовать безопасный DNS" и выберите DNS-провайдера, отличного от "Поставщика по умолчанию"
    * В Firefox откройте "DNS через HTTPS", установите режим "Персональный", выберите "Выбрать провайдера/поставщика" и вручную укажите URL. Например: `https://dns.google/dns-query` (провайдер Cloudflare может быть заблокирован)
    * Windows 11 позволяет включить Secure DNS в настройках самой ОС — [инструкция здесь](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 этот вариант рекомендуется
    * На роутерах Keenetic активируйте параметр "Транзит запросов". Если его отключить, настройка и работа Secure DNS на компьютере могут быть нарушены

2. Получите zip/rar-архив с [последнего релиза](https://github.com/Barbnorescue/zapret-discord-youtube/releases/latest)

3. Откройте свойства загруженного архива и включите "Разблокировать". При использовании 7-Zip или PeaZip этот пункт можно пропустить

4. Распакуйте архив в путь без кириллицы и специальных символов

5. Откройте нужный файл
    * Для поиска рабочей стратегии: **`service.bat`** → `Run Tests` → `Standard tests` → `All configs`
    * Для добавления в автозапуск: **`service.bat`** → `Install Service` → выберите подходящую стратегию

## ℹ️Краткие описания файлов

- [**`general.bat ...`**](./general.bat) — ручной запуск стратегии

  Такой запуск удобен для проверки стратегий. Результат зависит от множества условий, поэтому **перебирайте разные варианты (ALT, FAKE и другие), пока не найдёте подходящий именно вам**

- [**`service.bat`**](./service.bat) — автозапуск и дополнительные операции:
  - <ins>**`Install Service`** — добавить выбранную стратегию в автозапуск (services.msc)</ins>
  - **`Remove Services`** — удалить стратегию и WinDivert из служб
  - **`Check Status`** — проверить состояние обхода и служб, включая стратегию в автозапуске и WinDivert
  - **`Game Filter`** — включить или выключить обход для игр и прочих сервисов, использующих UDP и TCP на портах выше 1023.  
  **После изменения режима стратегию необходимо перезапустить.**  
  Текущее состояние (включено/выключено) показывается в скобках.
  - **`IPSet Filter`** — изменить режим обхода ресурсов из `ipset-all.txt`.  
  Это может помочь при проверке ресурса, который без zapret работает  
  В скобках отображается состояние:
    - `none` — ни один IP не проверяется
    - `loaded` — IP проверяется на наличие в списке
    - `any` — под фильтр попадает любой IP  
  - **`Auto-Update Check`** — включить или выключить автоматический поиск обновлений
  - **`Replace active fakes`** — заменить текущий фейк другим файлом из `bin`
  - **`Update IPSet List`** — загрузить актуальный `ipset-all.txt` из репозитория
  - **`Update Hosts File`** — обновить hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовому чату Discord**</ins>
  - **`Check for Updates`** — вручную проверить наличие обновлений
  - **`Run Diagnostics`** — найти распространённые причины неисправности zapret.  
  В финале можно очистить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда возвращает его работоспособность
  - **`Run Tests`** — открыть проверку стратегий:
    - `Standard tests` — проверка сайтов из `utils/targets.txt`
    - `DPI checkers` — проверка DPI у разных провайдеров, включая Cloudflare и Amazon

## ☑️Распространенные вопросы и проблемы

### После запуска `general*` ничего не происходит

- При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe (обход), видимый на панели задач.  
Если его нет, обратитесь к [#522](https://github.com/Barbnorescue/zapret-discord-youtube/issues/522)

### Не подходит ни одна стратегия
- Откройте командную строку с правами администратора
- Выполните по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер

### Не работает Telegram (веб-версия)
Откройте **`service.bat`** и выберите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открывшегося блокнота
  - Через текстовый редактор, запущенный от имени администратора, откройте файл `hosts` в созданной папке
  - Вставьте скопированное в конец `hosts` (либо замените ранее добавленные аналогичные строки)
  - Сохраните файл и проверьте подключение. Если результата нет, убедитесь, что `hosts` действительно был сохранён.

#### Работа не гарантируется. Если способ не помог, используйте [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) вместе с [локальным прокси](https://github.com/Barbnorescue/tg-ws-proxy) или любым публичным прокси.

### Обход не работает или прекратил работать

> [!IMPORTANT]
> **Стратегии могут устаревать и переставать работать.**
> Обнаруженная стратегия может какое-то время выполнять свою задачу, а затем перестать работать из-за её выявления.
> Здесь есть много вариантов обхода. Если готовые варианты не помогают, создайте новую стратегию на основе одной из имеющихся и измените её параметры.
> Описание параметров доступно [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- В `service.bat` откройте `Run Diagnostics` и проверьте отсутствие ошибок

- Удостоверьтесь, что адрес нужного ресурса присутствует в списке доменов или IP

- Перепробуйте остальные стратегии, включая **`ALT`**, **`FAKE`** и другие

- Выполните полную переустановку по инструкции ниже

- Дополнительная информация: [#765](https://github.com/Barbnorescue/zapret-discord-youtube/issues/765)

### Как полностью переустановить или обновить?
- Сохраните добавленные вами ресурсы и данные
- Перезапустите устройство
- Выполните `service.bat` → `Remove Services`
- Запустите `service.bat` → `Run Diagnostics`; исправьте найденные ошибки и в конце выберите Y
- Удалите каталог zapret
- Возьмите свежую версию [со страницы релизов](https://github.com/Barbnorescue/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`)
- Нажмите ПКМ по архиву и откройте свойства. Если внизу справа есть "Разблокировать", установите флажок, нажмите применить и затем ОК
- Распакуйте архив в новую папку в корне диска, без пробелов и специальных символов
- Запускайте разные `general`-скрипты и проверяйте ресурсы. Если интернет не работает, закройте программу (значок замка находится на панели задач) и выберите другую стратегию
- Найдя рабочий вариант, добавьте его в автозапуск через `service.bat` → `Install Service` → нужная стратегия

### Игра или приложение не работает при включённом zapret

- В `service.bat` проверьте, что `Game Filter` имеет состояние **`disabled`**, а `IPSet Filter` — **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит сообщает о WinDivert

- Инструкция находится здесь: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- В [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### После удаления через [**`service.bat`**](./service.bat) WinDivert остаётся среди служб

1. Получите имя службы командой в командной строке Windows (Win+R, `cmd`):

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите найденную службу:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8Fиспользование)
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться
- Попробуйте остальные стратегии, особенно если раньше всё работало
- См. [#251](https://github.com/Barbnorescue/zapret-discord-youtube/discussions/251)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что включён [Secure DNS](#%EF%B8%8Fиспользование)
- Сначала определите стратегию, на которой открывается YouTube, и запустите её
- В `service.bat` выберите `Run Diagnostics` и очистите кэш Discord
- Проверьте приложение Discord и выясните, помогла ли очистка кэша
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно пользоваться ею
- Если Discord не открывается и в браузере, ещё раз проверьте все стратегии: YouTube и Discord могут работать на разных вариантах
- См. [#252](https://github.com/Barbnorescue/zapret-discord-youtube/discussions/252)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/Barbnorescue/tg-ws-proxy)
- Либо используйте бесплатные MTProto-прокси из интернета

### Не работают игры

Игр много, поэтому проверить и исправить каждую из них невозможно.

В качестве наиболее универсального варианта:
- через `service.bat` обновите ipset и включите `Game Filter`
- если это не помогло, дополнительно включите `ipset any`

Учтите: `ipset any` может нарушить открытие множества сайтов. Не оставляйте его включённым постоянно. Лучше выяснить все IP-адреса игры и добавить их в `ipset-all.txt`

Если результата нет, создайте обсуждение в разделе [Discussions](https://github.com/Barbnorescue/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Проблемы нет в списке

- Опишите её [здесь](https://github.com/Barbnorescue/zapret-discord-youtube/issues)

## 🗒️Добавление адресов прочих ресурсов

Дополнительные адреса для обхода добавляются в следующие файлы:
- **`list-general-user.txt`** — домены; поддомены учитываются автоматически
- **`list-exclude-user.txt`** — домены, которые нужно исключить, например когда IP-сеть уже указана в `ipset-all.txt`, но конкретный домен фильтровать не требуется
- **`ipset-all.txt`** — IP-адреса и подсети
- **`ipset-exclude-user.txt`** — IP-адреса и подсети, которые следует исключить
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`
